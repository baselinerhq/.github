## Repository hygiene you can measure

We build **[baseliner](https://github.com/baselinerhq/baseliner)** — a single
dependency-free binary that scores your repo fleet against **your own** hygiene
baseline. No server, no GitHub App, no org admin: point it at a GitHub org (or
local checkouts) and get a 0–1 score per repo, plus actionable findings as a
console table, JSON, or SARIF.
